# Ktlint API Consumer

This module contains a very basic example of how to implement an API Consumer on top of the Ktlint 2.x API. If you want to implement your own custom API Consumer than you can copy this module into a stand-alone project or as submodule into another project.

You are strongly discouraged to use Ktlint 1.x API which can be recognized by package names starting with "com.pinterest.ktlint". Those packages are deprecated and will be removed in a future version of Ktlint without further notice.
